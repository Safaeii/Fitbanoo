## 🚀 اجرای پروژه

ابتدا مخزن را دریافت کن:

```bash
git clone YOUR_REPOSITORY_URL
```

و وارد پوشه پروژه شو:

```bash
cd fitbanoo
```

وابستگی‌ها را نصب کن:

```bash
npm install
```

سرور توسعه را اجرا کن:

```bash
npm run dev
```

سپس آدرس زیر را در مرورگر باز کن:

http://localhost:3000
